# Desa Ajaib

## 1. Tema dan cara bermain

**Desa Ajaib** adalah game edukasi petualangan 2D untuk pemain tunggal. Pemain mengendalikan Lili saat menjelajahi desa dan membantu warga melalui misi interaktif. Permainan memadukan eksplorasi, interaksi dengan karakter, serta puzzle sederhana seperti mencari, mengumpulkan, membagikan, dan menyeret benda ke tempat yang tepat.

Game ini mengangkat tema kepedulian, berbagi, kerja sama, dan merawat lingkungan. Tidak ada pertarungan; tantangan diselesaikan dengan mengikuti petunjuk dan melakukan tugas di setiap level.

## 2. Level dan tujuan

Alur permainan terdiri dari lima level. Misi yang selesai membantu membuka bagian berikutnya, dan progres dapat disimpan untuk dilanjutkan.

| Level            | Tema dan tujuan |
| ---              | --- |
| 1. Hutan         | Cari keranjang buah milik Tutu, ambil, lalu bawa kembali kepadanya. |
| 2. Padang rumput | Bagikan tiga stroberi kepada Lili dan tiga kepada Tutu dengan menyeret buah ke karakter yang tepat. |
| 3. Sungai        | Perbaiki jembatan dengan menempatkan empat papan dan dua tali pada posisi yang sesuai. |
| 4. Pesta desa    | Bagikan bekal kepada lima warga, lalu pasang empat perlengkapan pesta. |
| 5. Taman         | Pulihkan taman. Misi mencakup membersihkan sampah, mengumpulkan ranting, dan menyiram tanaman; dalam mode pahlawan, pemain menanam bibit, menyiramnya, lalu menempatkan bunga. |

### Mekanisme dan aturan

- Gerakkan Lili menggunakan tombol **A/D** atau tombol arah.
- Dekati warga untuk memulai atau melanjutkan interaksi misi.
- Ikuti petunjuk pada layar. Beberapa tugas dilakukan dengan menyentuh atau mengambil objek; tugas lain meminta pemain menyeret objek ke sasaran.
- Selesaikan tujuan level untuk membantu warga dan melanjutkan petualangan.
- Progres permainan dapat disimpan dan dilanjutkan dari menu.

Karakter utama adalah **Lili**. Ia bertemu Tutu dan warga desa lainnya, lalu membantu mereka menyelesaikan masalah di lingkungan sekitar.

## 3. Target pengguna

Game ini ditujukan untuk **anak-anak sekolah dasar kelas 1-3**. Kontrol dan tujuan dibuat sederhana agar anak dapat belajar melalui aktivitas langsung, dengan tema berbagi, membantu sesama, dan menjaga lingkungan.
